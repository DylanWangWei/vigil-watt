# 飞智黑武士 5 Pro

## 1. 接口与协议

只匹配手柄或 2.4G 接收器的 `37D7:2401`、厂商集合 `FFA0:0001`，
不支持 Dock 2（`37D7:6001`）或蓝牙。输出报告至少 33 字节且无报告编号；
查询为 `00 5A A5 01 02 00`，补零至接口声明的输出长度。每轮只发一次 GET_INFO，
随后读取输入流直到响应或超时。写入经插件开关与基类熔断控制，默认关闭。

响应从 `5A A5 01` 开始，可能带一个 HID 报告编号前缀；解析不假设具体输入报告编号。
相对帧头的 `[5]`
为设备类型（`82` 标准版，`90` / `91` 特别版），`[15..16]` 为大端固件版本；
只接受 `0x7141` 及以上。`[11]` 高半字节为状态（0 放电、1 充电、2 充满），
低半字节为 0–6 档；档位显示为 10、25、40、55、70、85、100%，**只是估算，
不是设备上报的精确百分比**。唤醒时最低档可能短暂成为初始化值。

依据：[VaderBatteryTray](https://github.com/vermi5/VaderBatteryTray) 的 Windows GET_INFO
实现和电量档位映射；[PeriTray](https://github.com/oneday5799/PeriTray) 记录同协议的
特别版设备类型。本项目尚未在真机上验证，蓝牙、充电底座和不同固件不在支持范围。
